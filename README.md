# TechLog — Site Institucional

Site institucional de empresa fictícia desenvolvido como atividade prática do **Curso Técnico em Desenvolvimento de Sistemas** (ETEC / Centro Paula Souza), nas disciplinas de **Desenvolvimento Web I** — Agendas 15 e 16.

---

## 📋 Sobre o Projeto

A **TechLog** é uma empresa fictícia de tecnologia e logística digital. Este projeto consiste em um site institucional responsivo, desenvolvido com HTML, CSS e JavaScript puro, apresentando informações da empresa, parceiros, serviços e perguntas frequentes.

---

## 🗂️ Estrutura de Seções

| Seção | Descrição |
|---|---|
| **Home** | Apresentação da empresa, missão, valores e objetivo |
| **Parceiros** | Empresas parceiras (Alpha, Beta e Gama) |
| **Serviços & Produtos** | Slideshow manual com os 5 principais serviços |
| **FAQ** | Perguntas frequentes sobre a empresa |

---

## ⚙️ Funcionalidades

- Menu lateral fixo com navegação por âncoras
- Slideshow manual de serviços com botões de navegação (‹ ›) e contador de slides
- Layout responsivo com W3.CSS
- Ícones via Font Awesome
- Links para redes sociais no rodapé

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3** (inline + W3.CSS framework)
- **JavaScript** (vanilla — slideshow manual)
- [W3.CSS](https://www.w3schools.com/w3css/) `v4`
- [Font Awesome](https://fontawesome.com/) `v4.7.0`
